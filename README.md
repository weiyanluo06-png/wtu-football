# 武汉纺织大学材料学院足球队网站1

> 绿茵逐梦・材聚一心

这是武汉纺织大学材料科学与工程学院足球队的静态展示网站，用于记录球队发展、赛事荣誉、球员阵容、赛程战绩和球队影像。

球队成立于 2020 年，由材料学院热爱足球的学生自发组建。网站当前收录 2024-25、2025-26 赛季阵容，以及 2023—2026 年间多项校内赛事记录。

## 网站内容

- **球队介绍**：展示建队背景、训练体系与团队文化。
- **赛事荣誉**：记录纺大杯、新生杯等赛事中的冠军、亚军和季军成绩。
- **球员阵容**：按赛季展示球员，并支持门将、后卫、中场和前锋位置筛选。
- **赛程战绩**：按赛事切换查看赛程和比赛结果。
- **精彩图库**：展示球队合影、比赛瞬间与颁奖照片。

## 功能亮点

- 响应式页面布局，适配电脑、平板和手机。
- 导航栏随滚动高亮当前栏目，并支持平滑跳转。
- 移动端折叠菜单和返回顶部按钮。
- 球员赛季切换与位置筛选。
- 多项赛事标签切换和战绩表格动画。
- 图片灯箱预览，支持前后切换、键盘方向键和 `Esc` 关闭。
- 数字计数与滚动渐入动画。

| 技术 | 用途 |

## 本地预览

项目是纯静态网站，可以直接在浏览器中打开 `index.html`。为保证资源路径和浏览器行为一致，建议在项目根目录启动本地静态服务器。

使用 Python 3：

```bash
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/
```

## 内容维护

### 更新球队信息、阵容或赛程

编辑 `index.html` 中对应栏目：

- `#about`：球队介绍
- `#honors`：赛事荣誉
- `#squad`：球员阵容
- `#schedule`：赛程战绩
- `#gallery`：精彩图库

新增球员时，请保留现有 `data-season` 和 `data-position` 属性格式，以确保赛季切换和位置筛选正常工作。新增赛事时，请保持赛事按钮与内容区域的 `data-tournament` 值一致。

### 更新图片

将荣誉或图库图片放入 `images/honors/`，再在 `index.html` 中更新对应的图片路径和替代文字。建议使用清晰、经过压缩的 JPG 或 WebP 图片。

### 调整样式与交互

- 页面颜色、排版、动画和响应式断点位于 `css/style.css`。
- 导航、筛选、标签切换和灯箱逻辑位于 `js/main.js`。

修改后请同时检查桌面端和移动端显示效果。

## GitHub Pages 部署

该项目可以直接从仓库根目录发布，无需构建步骤：

1. 打开 GitHub 仓库的 **Settings**。
2. 进入 **Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/ (root)` 目录。
5. 保存设置，等待 GitHub 完成发布。

## 浏览器兼容性

建议使用最新版 Chrome、Edge、Firefox 或 Safari。页面使用 `IntersectionObserver` 等现代浏览器特性，较旧浏览器可能无法显示部分滚动动画。
